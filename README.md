# NAZATIAN RUNNER

2D endless runner (HTML5 Canvas, vanilla JS). নাজাতীয়ান (Nazatian) runs through a madrasa courtyard chased by দারোয়ান চাচা (Darowan Chacha). Jump obstacles, collect coins, survive. Game over: "চল প্রিন্সিপাল হুজুরের কাছে".

Features: delta-time physics, chase meter, score/best/coins (localStorage), landscape + fullscreen request on Start, rotate-phone overlay, procedural chiptune music, separate music and effects toggles, pause, developer credits.

Controls: tap / JUMP button / Space / Up = jump; P or Esc = pause; Enter = start/restart.

Run: open `index.html`. Deploy: upload the folder contents to a GitHub repo, then Settings > Pages > Deploy from branch `main` / root.

Developer: Abdullah Al Fahim - Studio FCITY, est. 2026.

Limitations: fullscreen/orientation lock depend on browser support (Android Chrome supports them after the Start tap; iOS Safari does not). Not tested on real devices.
